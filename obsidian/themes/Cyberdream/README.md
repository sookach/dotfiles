# Cyberdream for Obsidian

A high-contrast, futuristic & vibrant theme for [Obsidian](https://obsidian.md), ported from the [cyberdream.nvim](https://github.com/scottmckendry/cyberdream.nvim) colorscheme.

## Installation

1. Copy the `Cyberdream` folder into your vault's theme directory:

   ```
   <your vault>/.obsidian/themes/Cyberdream/
   ```

2. In Obsidian, open **Settings → Appearance**.
3. Select **Cyberdream** from the Themes dropdown.
4. Toggle **Base color scheme** between *Dark* and *Light* for either variant.

## Features

- **Dark & light variants** using the official cyberdream palettes
- **High contrast** — flat surfaces, no shadows or glows
- **Sharp corners** — zero radius on tabs, buttons, modals and checkboxes, matching the cyberdream aesthetic
- **Vibrant syntax highlighting** — green strings, magenta keywords, blue functions, yellow values, cyan operators
- **Cyan accent** (`#5ef1ff` dark / `#008c99` light) used for links, focus states, checkboxes and icons
- **Markdown styling** — colored headings, underline-on-hover links, magenta-bordered blockquotes, purple tags, and type-colored callouts
- All styling uses official Obsidian CSS variables, so user settings (fonts, accent color, etc.) keep working
